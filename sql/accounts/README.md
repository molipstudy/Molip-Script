# 가입 및 회원 관리 적용

기존 `email-username-upgrade.sql`과 `../admin/member-edit-upgrade.sql`까지 적용한 운영 DB에서 **`../member-management-upgrade.sql` 하나**를 SQL Editor에서 실행합니다. 전체 작업은 한 트랜잭션으로 적용되며 자동 실행되지 않습니다.

- 신규 Script 가입 시 이름·전화번호·유저네임·가입 경로 검증 및 공용 프로필 저장
- 프로필 편집 시 이름·전화번호 필수, 이미 저장된 이름·전화번호 삭제 금지
- 전역 관리자의 회원 연락처 편집, 보유/공개 스크립트 및 진행 중 학습 조회
- 이메일 변경 API의 전역 관리자 권한 확인용 RPC

기존 회원은 삭제하거나 임의의 정보로 채우지 않습니다. 다른 서비스의 가입 계약은 유지합니다. 가입 폼 배포 전 SQL을 적용해야 이메일 확인 전에도 이름·전화번호가 프로필에 저장됩니다.

관리자 이메일 편집에는 Vercel Production 환경 변수 `SUPABASE_SECRET_KEY` 또는 기존 `SUPABASE_SERVICE_ROLE_KEY`가 필요합니다. 서버 전용 secret/service-role 키를 사용하며 `VITE_` 접두사를 붙이지 않습니다. 공개 publishable/anon 키와 다릅니다.

이메일은 Auth 관리자 API로 변경합니다. 비밀번호·UUID·관리자 권한·이메일 인증 플래그는 변경 요청에 포함하지 않습니다. 이메일 변경 실패 시 다른 프로필 항목의 저장 여부를 따로 안내합니다.

## 추가 적용

- `../signup-source-other-upgrade.sql`: 위 회원 관리 SQL 다음에 실행합니다. 가입 경로 ‘기타’와 별도 상세 문구를 저장하고 관리자 목록·필터·편집을 갱신합니다.
- `../support-upgrade.sql`: 사이트 문의·답변 기능을 추가합니다. `molip_support`는 비공개 저장 스키마이므로 Exposed schemas에 추가하지 않습니다. 기존 노출 스키마 `molip_script`의 권한 확인 RPC만 사용합니다. 별도 이메일 발송 설정은 필요하지 않습니다.

## 관리자 본문 열람 및 복사

`../admin/script-preview-upgrade.sql`을 실행하면 관리자 본문 열람과 스크립트 복사 RPC를 사용할 수 있습니다. 일반 회원은 본인 스크립트만, 서비스 관리자는 해당 서비스의 다른 회원 스크립트도 복사할 수 있습니다. 원본과 학습 기록은 수정하지 않고 본문·제외 단어 설정만 본인 소유 새 스크립트로 복사합니다. 새 테이블/노출 스키마 설정은 필요하지 않습니다.

## 관리자 대시보드 요약·그래프

`../admin/dashboard-summary-upgrade.sql`을 `support-upgrade.sql` 이후에 실행합니다. 기존 테이블의 가입자·스크립트·문의 현황을 읽는 `admin_dashboard_summary` RPC만 추가합니다. 운영 DB 실행은 별도로 진행하며 새 테이블이나 노출 스키마 설정은 필요하지 않습니다. 일반 회원·비로그인은 실행할 수 없고, 서비스 관리자는 해당 서비스 가입자만 조회합니다. 전역 관리자의 회원 요약은 통합 계정 전체 기준입니다.

방문 통계는 기존 서버 전용 Vercel 토큰으로 방문자·조회, 일별/시간별 집계, 페이지·경로·유입 사이트·국가·기기·브라우저·운영체제 및 UTM 분류를 조회합니다. 24시간·7일·30일을 지원하며 플랜/데이터 보관 기간에 따라 일부 항목은 제공되지 않을 수 있습니다. 없는 데이터를 0으로 대체하지 않습니다. 대시보드는 요약 3회, 상세 통계는 17회 조회를 최대 5개씩 병렬 실행하며 반복 폴링하지 않습니다. 고유 방문자를 항목별로 합산하지 않습니다.
